# 桌面 UI 设计

版本：0.5；日期：2026-10-07；状态：本次修订子代理审核通过（`reviews/06-ui-followup-review.md`），待用户批准。前序 UI v0.4 / 产品 v0.3 的通过记录保留于 `reviews/04-ui-revision-review.md`、`reviews/03-product-revision-review.md`。

## 1. 审核材料与边界

交互稿：`design/desktop-preview.html`。默认直接展示 App，无审核顶栏/底栏。按 Alt+Shift+P 打开浮动审核工具，或使用 `?review=1`；工具可切平台、色板、页面与异常状态，不属于产品 UI。示例作品/模型/路径/测试结果均为演示数据。设置只在内存，刷新会重置；头像仅在用户显式选文件后读取预览，不写盘。不保存 Key，不连接模型，CSP 禁止 fetch。反馈按钮为明确的用户外部导航。

当前仅为 UI 阶段。没有 Electron 窗口、原生按钮、磁盘事务、真实模型调用或安装版本，不能将原型检查作为 App 验收。原型的窗控是位置示意，最终使用系统按钮；关于页标注尚未发布，最终从实际安装包读取版本。

最终 App 复用原 React 工作台及 29 类面板，产品能力矩阵仍完整约束实现。原型只演示桌面差异。

## 2. 与 Web 保持一致

保留侧栏作品树/会话树、对话流/引用 chip/候选与批准入口、内容 Tab、MarkdownEditor 预览/编辑/分屏、版本与评论、草稿和编辑实例。新设置关闭不重挂载编辑器。语义令牌直接来自原 `globals.css`；标志复用温玉 SVG，Lucide 和中文字体均本地提供，来源见 `assets-provenance.json`。阅读面保留纸纹，玄墨界面保留墨石纹理。

允许桌面差异：顶部栏内系统按钮/视图导航、侧栏本地用户资料、作品路径授权、离线创建、用户设置、迁移/恢复。只有 paper / ink 两套色板，跟随系统是主题选择规则。

## 3. 无边框工作台

取消独立顶部标题栏和底部全局状态栏。左导航、中对话、右内容填满窗口，垂直分隔线从顶部贯穿到底部。首启保持原两栏，内容展开后为三栏；常规侧栏初值 260px，沿原布局逻辑分配余下空间。

左导航顶部 47px 栏内，macOS 系统交通灯、后退、前进、侧栏展开/收起依次排列。截图参考用于位置与风格，顺序按用户文字要求。按钮组下方保留原品牌与创作入口。侧栏收起时，当前面板头部提供相同导航工具；窄窗侧栏浮层从 y=0 起，不留标题带。

Windows 窗控在右上角当前可见面板头部，预留约 138px 安全区，不遮住 Tab/内容切换。顶部各栏的空白可鼠标拖动；按钮、输入、菜单、系统控件不拖动。Mac 最后窗口关闭/Dock重开、全屏、Windows 吸附、DPI、失焦状态必须在真实桌面验证。

后退/前进在窗口内视图历史移动，边界禁用，不操作网页浏览历史。原型仅演示正文/新对话之间的历史按钮状态，最终按原工作台视图完整接入并保留草稿。

## 4. 设置容器

最大约 960 × 730px，空间不足时填可用区域，右内容独立滚动。分类宽 172px，窄窗 126px；分类顺序固定：通用、用户、模型、界面、快捷键、关于我们。头部有设置标题、说明与关闭；没有底部保存/取消。

除用户编辑外，合法设置修改即时响应，收到原子本地回执后显示已更新。输入无效保留待修正内容，上一有效配置继续使用；持久化失败显示原因、保留待处理修改和重试入口。切组、关闭不回滚已确认配置，也不出现未保存确认框。原型只演示这些状态，不承诺真实持久化。

主对话框与配置子对话框分层：最高层获得焦点，下层 inert，Tab/Shift+Tab 循环，Escape 关闭最高层；确认清除/删除/停用、测试费用与目录迁移仍是独立明确操作。设置打开后作品草稿保持。

## 5. 六类设置

| 页面 | 结构与交互 |
| --- | --- |
| 通用 | 数据根（只读路径＋迁移）、默认作品父目录（选择）、启动恢复、备份间隔/保留数、备份恢复和配置导入导出。作者资料移到用户页。父目录不构成建书授权。 |
| 用户 | 用户卡片：头像、笔名、编辑按钮。编辑打开独立对话框：本地头像选择（PNG/JPEG/WebP ≤2MB）、笔名、邮件；空笔名/无效邮件行内校验，左右布局：左侧可点击头像占满表单高度，右侧笔名与邮件；底部「取消」「保存」。仅保存并收到回执后更新卡片和侧栏。取消、X、Escape 丢弃草稿，重新打开读取已确认资料。存储失败保留草稿和旧资料；迟到图片读取不能写入已取消会话。无需登录，不发送邮件。 |
| 模型 | 右侧只显示「文本模型」「文生图模型」两组列表，每组有添加入口、计数和独立空态。图像理解仍属文本模型。两类选择状态分离，文生图选择不能替换对话模型；改组或删除不自动选择其他模型。行显示展示名、供应商/模型 ID、可用状态与编辑/选择/删除操作。添加或编辑打开独立配置对话框，未补全配置保留可续写草稿，不能调用。 |
| 界面 | 「主题」三个选项：宣纸、玄墨、跟随系统。取消单独的跟随系统开关；mini 工作台图示重新绘制，保留三栏、标志、候选卡、正文与输入区视觉。跟随系统解析为 paper / ink；监听系统外观变化。字号、行距、界面缩放及布局恢复即时响应。 |
| 快捷键 | 搜索框在上；同行右侧恢复默认；下方命令/键帽/录制列表。按命令或组合键过滤，无结果空态。录制拒绝空值、重复及系统保留键；有效绑定即时更新。取消单次录制保留原绑定。去掉底部编辑器说明。 |
| 关于我们 | 当前版本（来自 App 实际版本；原型显示尚未发布）、问题反馈/填写反馈（仓库 issue 新建页）、帮助文档/查看文档。预留 https://xuanxiang.ink/docs，上线后启用，当前禁用并标注尚未上线。 |

### 模型配置对话框

字段顺序：供应商 → 协议 → 该供应商/协议必要属性。预设 OpenAI、Anthropic、Google、xAI、DeepSeek、Kimi、ZAI、Xiaomi、Qwen、MiniMax 与自定义。主协议只有 OpenAI / Anthropic；预设自动选择，自定义初值为空且必须选择。字段规范及官方来源见 `provider-ui-presets.md`。

通用属性：展示名、Base URL、模型 ID、API Key、启用、能力/用途。Key 不回填明文，留空保留已确认密钥，清除按钮独立确认。改供应商/协议/端点立即撤销旧 Key，禁止跨供应商沿用授权。输入框缺字段、非法地址或预算时显示错误，不能进行连接测试；未完成的新记录显示待补全。

OpenAI 可选 Organization/Project；OpenAI / xAI / 自定义 OpenAI 可在高级项选择请求形式（不作为第三协议）。Anthropic 必填输出上限，思考模式按实际模型可选 adaptive 或 enabled；enabled 预算需 ≥1024 且小于输出上限（原型不展示交错思考扩展）。Google 走官方 OpenAI 兼容接口，思考能力按模型实际支持；DeepSeek/Xiaomi 的思考类型与其他供应商区分。默认不发送额外思考参数。Qwen 区域/工作空间端点由用户复制；Kimi 中国站/国际站提示不同 Key，不自动拉取模型列表。

有效配置自动更新，不自动请求。「测试连接」再确认端点/模型/请求类型及可能费用：文本模型为短文本，文生图模型为明确提示词与 1 张图片，不用文本请求冒充图像验证；测试可停止，错误结果就地显示。删除/禁用/清除 Key 立即取消任务与后续重试，保留候选和草稿，关闭设置不能复活授权。

## 6. 目录、迁移与恢复

沿用已审 v0.3 流程：每次新建必须重新取得作品目录授权；建议目录不等于确认。非空冲突、已绑定目录、只读等具体错误紧邻字段；未选择时创建禁用。放入对话草稿仅挂起授权/模板，不发送模型；手动创建打开空概览，模板仍在输入草稿。取消清除挂起授权，新对话隔离，第二作品不得复用已绑定目录。

迁移显示源、当前权威根、显式目标与清理范围。提交前可取消，提交后所有关闭/切换路径守卫，Windows 路径同步更新；快照在新根，作品与未知文件不清理，旧副本待清理不能算完整成功。根失联不悄悄退回旧根；快照校验后选恢复目录，损坏备份不可恢复。草稿恢复先比较，进入可编辑且未提交的恢复稿。关闭前保存失败提供重试、导出、取消关闭，X/Escape 按取消关闭处理。

## 7. 审核与继续条件

本次用户修改覆盖：无顶/底栏、窗控/箭头/侧栏开关、模型列表与供应商优先子对话框、用户/关于页、三种主题模式与图示、即时设置、快捷键搜索布局。本次新增分组模型、Web 用户菜单与手动保存用户资料。新版检查与截图记录于 `design/preview-verification.md`。v0.3 的 129 项与 v0.4 的 157 项均为历史证据，不自动沿用为 v0.5 通过。

子代理检查产品一致性、字段/密钥边界、实时反馈、窄窗可达性、分层焦点、旧目录/恢复保护及证据真实性。**用户明确批准此 UI 稿后才进入技术方案、测试用例和 TDD App 实现。** 当前请求是修订设计，不构成批准。

## 8. Web UI 复用边界与来源

桌面专属差异之外，最终 App 完全沿用当前 Web UI，不另做桌面创作界面。下列是实际实现的来源绑定，不是设计灵感；迁移需保留组件和其交互，不用此静态稿替代 React 原件。

| UI 范围 | Web 原来源 | 桌面允许差异 |
| --- | --- | --- |
| 分栏/布局/内容容器 | `src/components/layout/DashboardShell.tsx` | 去掉独立顶栏/全局状态栏，窗控/视图历史与拖动安全区 |
| 树与底部账号菜单 | `src/components/layout/SidebarTree.tsx`（账号菜单 2089–2169） | 本地资料；原向上菜单保留头像、笔名/邮件、外观切换，加入设置、去除旁侧齿轮；移除平台登录/退出与管理员链接 |
| 菜单容器/键盘 | `src/components/ui/dropdown-menu.tsx` | 最终复用原 DropdownMenu，原型仅演示结构与 Escape/外部点击/方向键 |
| 对话、引用、候选与任务 | `src/components/layout/ChatPanel.tsx` 及原子组件 | 作者模型来源与目录授权；其他布局/组件不变 |
| 正文编辑/预览/分屏 | `src/components/editor/MarkdownEditor.tsx` | 本地服务接入；保留编辑实例、自动保存、评论锚点、候选批准 |
| 全部其余创作面板、按钮、Tab、向导 | `source-inventory.json` 与能力矩阵列出的原组件 | 只加明确授权的作品目录与离线手动创建；其余不重设计 |
| 主题/标志/图标 | 原 `src/app/globals.css`、温玉 SVG、Lucide | 两色板不变；设置中的主题示意图是用户指定的桌面专属改动 |

底部用户触发器沿用 Web 24px 头像、12.5px 姓名、10.5px 等宽邮件、7px 圆角；弹出菜单向上左对齐，标签为 32px 头像、姓名与邮件，下方为原外观行（宣纸/开关/玄墨）与新增设置。菜单切换主题是显式选择 paper/ink，覆盖此前系统跟随；系统跟随仍可在界面设置选择。菜单关闭还原触发器焦点。

编辑用户没有「修改自动更新」或「重试更新」。头像列与右侧属性列在表单区域等高；点击头像打开系统文件选择。图片只在草稿预览，保存时与属性一次提交。所有取消路径及重新打开都会取消读取/隔离异步会话；失败再次点击保存，成功返回用户卡片。其他自动设置和模型撤销操作不改为手动保存。
