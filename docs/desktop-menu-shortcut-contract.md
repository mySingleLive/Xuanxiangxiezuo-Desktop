# 桌面菜单、外观与快捷键产品补充

版本：0.1；对应产品 v0.8 / UI v0.9；日期：2026-10-07。此文档是产品/UI 修订，技术方案仍待用户批准 UI 后产出。

## 菜单位置和命令

macOS 在系统桌面顶部原生菜单栏提供「玄香、文件、编辑、视图、窗口、帮助」。玄香为用户指定的菜单名，其余品牌仍为玄香印。设置、关于、隐藏/显示、服务、退出放玄香菜单；文件承载作品创建/打开、对话创建、保存/导出、关闭标签；编辑提供撤销/重做、剪切/复制/粘贴/纯文本粘贴、全选、查找/替换；视图提供三种正文模式、面板显隐、缩放、行号/换行；窗口提供最小化、最大化/全屏、关闭；帮助提供文档和反馈。系统保留角色与操作不可被任意重绑定。

Windows 保持无标题栏，在右上角最小化/最大化/关闭组的左侧加入菜单图标。展开五项「文件、编辑、视图、窗口、帮助」，各项打开二级菜单；设置/退出在文件、关于在帮助。按钮属于非拖动区域；窗控与菜单共用安全区，不压住内容标签。菜单在正常三栏、侧栏收起、内容区隐藏/全屏及窄窗均可达。Escape 逐层返回，方向键/Enter 导航，外部点击退出；平台切换关闭旧菜单。

原生呈现参考 [Electron Menu](https://www.electronjs.org/docs/latest/api/menu)：macOS application menu 与 Windows window menu 的位置不同；最终接入原生菜单/角色及自定义入口，原型中的 macOS 桌面条仅用于审核示意，不是在 App 内添加标题栏。浏览器不能证明原生菜单或系统窗控已实现。

菜单和快捷键使用同一稳定命令 ID、标签、可用条件和绑定来源。菜单显示当前已确认快捷键，改绑定后同步，不能存在两套映射。编辑命令作用于菜单打开前聚焦的编辑实例/输入框，不能因菜单抢焦把正文操作路由到其他输入。只读预览不允许剪切/粘贴修改；复用 Web 的 MarkdownEditorHandle / use-editor-commands 和 Monaco 撤销栈、版本/自动保存契约。应用菜单不绕过用户批准候选稿边界。

## 可用模型下拉与参数

预设供应商仅显示 API Key 和「可用模型」下拉列表框。添加时保持多选，编辑单一已保存记录时单选；收起显示选择数量和名称摘要，展开显示搜索、家族 Logo、模型名/ID、已添加禁选及无结果状态。列表有固定最大高度并滚动，窗口不足时向上展开/限制高度。切供应商清除该草稿 Key 和型号，不保存；测试开始关闭列表并锁定入口/搜索/选项，结束才恢复。目录再多也不拉长主配置框。完整真实目录由最终供应商能力目录提供，示例不冒充全量。

GPT 家族使用黑白 OpenAI 标，宣纸黑色/玄墨白色；月之暗面供应商与 Kimi 模型家族区分，Kimi 使用黑色圆角块、白色 K 图形。用户指定的 Z.ai 图形继续保留。图标资源记录来源和指纹，不执行外部包代码。

自定义配置去掉「输出上限」输入。上下文上限可为空，或使用正整数 / K / M 表示 token 数（128K = 128000，1M = 1000000，十进制）；不接受零、负数、未知单位和小数 token。保存时规范化整数，显示时可保留友好单位。该值是作者提供的能力提示，不能据此自动确认供应商能力。隐藏输出参数仍按协议/模型元数据产生合法默认值，Anthropic 等必要字段不因删输入而漏发，也不要求用户通过隐藏字段修复校验。

## 外观

保留三主题与纯图形主题缩略图。在外观页把「界面与正文」拆为两块：界面含界面字体、界面字号、缩放；正文含正文字体、字号、行距、显示正文行号、正文自动换行。字体选择系统默认/可用本地字体，不联网下载；不可用时回退并提示实际字体。正文字体/字号/行距适用于阅读及编辑，行号只在编辑/分屏左侧源码区显示；预览永远无行号。自动换行默认关闭，只控制编辑/分屏源码，阅读预览保持 Web 书页排版。无需关闭/重开编辑器；修改不能丢失未保存内容、选区、评论锚点或撤销栈。失败继续使用已确认配置，保留待处理值和重试。

## 快捷键覆盖与作用域

搜索框、右侧恢复默认、下方列表保留，新增按类别过滤和作用域/默认值显示：应用菜单、Markdown 编辑器、AI 输入框、普通文本输入框。所有菜单动作（包括未绑定动作和原生保留动作）均有条目；多个菜单引用同一动作只占一个 ID。Markdown 包括文字格式、标题1–6、链接/图片、引用/列表/代码/表格、查找替换、定位/选择/多光标、缩进/行操作、评论和编辑器视图，以及当前装配 Monaco 的全部可用动作；AI 输入包括发送/换行/停止、引用候选导航/确认/关闭、模型选择与会话搜索；普通输入包含剪贴板、撤销重做、光标/词/行首尾/全文选择、删除和确认/取消。

最终 App 从当前 Monaco 实例的动作与 keybinding 注册信息补齐全部受支持动作，不靠手写清单截断默认能力；命令名、内部 ID、作用域、当前键和默认键都可搜索。静态原型列出桌面命令及相关代表性编辑动作，不能据其条数宣称已经枚举/执行了真实 Monaco 全部动作。

冲突按作用域和同时激活条件判断：全局与任何局部冲突；同类输入冲突；互斥的 Markdown 与 AI/普通输入可复用组合。相同共享编辑 ID 为一条绑定，菜单与输入场景复用。支持 chord 组合，区分平台，macOS 绑定不因切 Windows 被改成另一组合。IME 组合期间不触发发送/菜单/热键，菜单或对话框已消费的 Escape 不再触发停止任务。录制过程中组合不执行原命令。系统保留键显示但禁止覆盖；普通功能未绑定仍可通过菜单或命令入口操作。恢复默认覆盖当前平台全部自定义绑定，需要明确确认，取消保持原值。

## 本阶段验证边界

本轮只验证原型菜单层级、显示/搜索/绑定/冲突、模型滚动选择和草稿隔离、字体/行号/换行表现、窄窗/主题/平台回归。原型不注册系统热键、不操作真实剪贴板或生成接口、不执行原生退出/磁盘保存，不伪造完整 Monaco 或 Electron 验收。原生菜单、菜单打开前焦点、编辑命令、键盘布局/IME/辅助功能及两平台安装包均须进入最终测试用例并在真实 App 验证。
